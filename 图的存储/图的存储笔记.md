## 邻接矩阵
1、函数中定义变量已经写了*G，则在后续的调用函数的时候直接写G就行，比如说：
```
int matrix_locate_vertex(MatrixGraph *G, VertexType v, VertexType w){}
后续调用：
matrix_locate_vertex(G, v)
```
2、添加一个新的顶点以后，邻接矩阵里面的新行和新列都需要进行初始化，全部调整成0。
3、记得在添加一个新顶点的时候判断顶点的数量有没有达到MAX_VERTEX_NUM
## 邻接表1
1、注意vertex[]为VNode类型，在插入点的时候要利用好vertex[].data和vertex[].firstarc两个关键值
2、在邻接表插入一个新的边需要采用头插法
3、邻接表插入一个新的边需要先通过遍历判断这个边是否已经存在：DG只需要查一次（一个方向），而UDG需要正反查两次（无向图相当于两个方向）。
4、adjvex这个特征对应的不是v或者w，而是v_index和w_index。
## 邻接表2
1、如果想使用快慢指针，那不需要使用malloc创建两个指针，只要声明变量即可，后续直接赋值到图中的ArcNode
2、指针访问成员用->不用.
3、删除分四步：
    删掉v的所有出边、遍历所有其他顶点的邻接表，删除指向v_index的入边、将vertex数组中v_index后面的元素都前移一位、更新所有边的adjvex；大于v_index的减1（因为索引变了）
4、对于删除首节点处理需要单独注意。以下有一个示例
```
while (cur != NULL){
            if (cur->adjvex == v_index){
                ArcNode *temp = cur;
                cur = cur->nextarc;
                if (prev == NULL)//这里特意指出prev == NULL的情况
                    G->vertex[i].firstarc = cur;
                else
                    prev->nextarc = cur;
                free(temp);
                G->arcnum--;
            }else{
                prev = cur;
                cur = cur->nextarc;
            }
        }
```
5、使用temp进行free时，temp不能和cur重合，否则cur也会被释放掉
