## AVL添加
1、新节点高度应该是1

2、new是关键字，在添加新节点的时候不要使用new，可以用new_node之类的

3、max不是C中的标准函数，需要定义

4、这个AVL添加有一个很关键的思维在于自身的递归，在avl_insert里面再使用自身函数实现类似于while的感觉但是比while要更加方便。

5、关键流程就可以总结一下：（写左旋操作右旋操作函数、高度计算函数、平衡因子计算函数、更新高度函数）然后依次执行以下操作：（1）判空排除特殊情况；（2）递归找到需要插入的值放在哪个位置（3）更新节点高度（4）计算平衡因子（5）分类判断LL/LR/RR/RL，进行操作（6）返回root。

## 哈希表创建

简而言之就是先创建一整个table，再依次对于其中的bucket初始化（全部用malloc）
```
HashTable *table = (HashTable *)malloc(sizeof(HashTable));
table->bucket = (HashEntry **)malloc(sizeof(HashEntry *) * size);
for(int i = 0; i < size; i++){
    table->bucket[i] = NULL;
}
```
然后对于table和bucket判空，size赋值回table->size即可

## 哈希表添加

1、先对所有的关键字类型进行辨析。这里用了一个联合体(Union)的方式，意思是：一块内存，多种解释方式。意思是：
```
union {
    char  *str_value;   // 解释为字符串指针
    double dbl_value;   // 解释为浮点数
    int    int_value;   // 解释为整数
} key;
// 这里的三者是相互覆盖的。
```

哈希表是通用的，不只想存 <string, int>，还想存 <string, double>、<int, void*>、<double, long> ...各种组合。

用 union 后，一套 HashEntry 结构体就能应对所有场景，不用写 HashEntryStrInt、HashEntryStrDbl、HashEntryIntInt ... N 套结构体。

2、本题告诉我们键类型为char*，元素类型为int；意思就是这次key用str_value, value用int_value；

3、**成员是指针的时候，需要深拷贝**在将提供的const key赋值给新的结构体上时候，直接赋值是有问题的，需要采用深拷贝的方式，如下；
```
new_entry->key.str_value = (char *)malloc(strlen(key) + 1);
strcpy(new_entry->key.str_value, key);
```
在hash的成员中
```
// key union 中有三种可能：
union {
    char  *str_value;   // ← 指针！需要深拷贝
    double dbl_value;   // ← 普通值，直接赋值
    int    int_value;   // ← 普通值，直接赋值
} key;

// value union 中有六种可能：
union {
    char  *str_value;   // ← 指针！需要深拷贝
    double dbl_value;   // ← 普通值，直接赋值
    int    int_value;   // ← 普通值，直接赋值
    long   long_value;  // ← 普通值，直接赋值
    void  *ptr_value;   // ← 指针！需要深拷贝（但用途复杂）
} value;
```
